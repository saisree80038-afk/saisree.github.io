# Agro Infinity

Build a premium, futuristic, fully responsive personal portfolio website for a Software Developer and Front-End Web Developer. The design should feel modern, innovative, tech-focused, and suitable for recruiters, clients, and hiring managers.

Design Requirements

Futuristic UI with glassmorphism, subtle gradients, smooth animations, and modern typography.

Dark theme as default with optional light mode toggle.

Professional color palette using shades of blue, purple, cyan, and white.

Smooth scrolling and page transitions.

Fully responsive across desktop, tablet, and mobile.

High-performance and SEO-friendly.

Interactive hover effects and micro-animations.

Modern developer aesthetic inspired by AI, coding, and futuristic technology.

Include animated background particles, grid effects, glowing elements, and subtle code-inspired visuals.
